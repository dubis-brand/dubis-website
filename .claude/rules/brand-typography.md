# Brand Typography — Slogan Map

## Mixed-Size Typography Rule
Each slogan uses a KEY POWER WORD in huge bold uppercase (3-5x larger), with setup/connecting words in smaller text. **NEVER write slogans in uniform font size.**

## Design Rules for Image Generation
- POWER WORD must be 3-5x larger than surrounding text
- White text on dark garments, dark text on light garments
- Bold sans-serif font (condensed/impact style)
- Front: small "DUBIS™" on left chest only
- Back: slogan ONLY — NO DUBIS logo or branding on back
