הגדרת Credentials חסרים
מדריך שלב-בשלב להגדרת המשתני סביבה החסרים בפרויקט
01
Gmail OAuth Credentials
גישה ל-Gmail API לסריקת הזמנות
טרם הוגדר
  1. היכנס ל-Google Cloud Console
  2. צור פרויקט חדש או בחר פרויקט קיים מהתפריט העליון
    אם יש כבר פרויקט DUBIS — בחר אותו. אחרת לחץ "New Project".
  3. הפעל את Gmail API
    • עבור אל: APIs & Services → Library
    • חפש "Gmail API"
    • לחץ על התוצאה ואז לחץ "Enable"
  4. צור OAuth 2.0 Credentials
    • עבור אל: APIs & Services → Credentials
    • לחץ "Create Credentials" → "OAuth Client ID"
    • Application type: Web application
    • Name: DUBIS Gmail Scanner
    • תחת "Authorized redirect URIs" — לחץ "Add URI" והדבק:
    • לחץ "Create"
    • העתק ושמור את CLIENT_ID ו-CLIENT_SECRET
  5. קבל Refresh Token דרך OAuth Playground
    • לחץ על אייקון גלגל השיניים (ימין עליון) → סמן "Use your own OAuth credentials"
    • הכנס את CLIENT_ID ו-CLIENT_SECRET
    • בשלב 1 (שמאל) — חפש "Gmail API v1"
    • בחר את הסקופ: https://www.googleapis.com/auth/gmail.readonly
    • לחץ "Authorize APIs" → התחבר עם dubis.brand@gmail.com
    • בשלב 2 — לחץ "Exchange authorization code for tokens"
    • העתק את Refresh Token מהתשובה
  6. הוסף ל-Vercel — Settings → Environment Variables
    • GMAIL_CLIENT_ID — הערך מהשלב הקודם
    • GMAIL_CLIENT_SECRET — הערך מהשלב הקודם
    • GMAIL_REFRESH_TOKEN — הערך מהשלב הקודם
    • ודא שכל משתנה מוגדר ל-Production + Preview
    חשוב לאחר הוספה: בצע Redeploy מ-Vercel Dashboard (Deployments → ··· → Redeploy) כדי שהמשתנים יכנסו לתוקף.
02
Instagram System User Token
פרסום תוכן אוטומטי לאינסטגרם
טרם הוגדר
  1. היכנס ל-Meta Business Suite
  2. עבור אל System Users
    • בתפריט שמאל — Settings → Business Settings
    • בסרגל הצד — Users → System Users
  3. צור System User חדש
    • לחץ "Add"
    • Name: DUBIS Publisher
    • Role: Admin
    • לחץ "Create System User"
  4. הוסף נכסים ל-System User
    • לחץ "Add Assets"
    • בחר Instagram Accounts → בחר את חשבון DUBIS
    • הפעל את כל ההרשאות הזמינות
    • לחץ "Save Changes"
  5. צור Access Token
    • לחץ "Generate New Token" (על ה-System User)
    • בחר את האפליקציה (DUBIS Publisher, או צור אפליקציה חדשה)
    • בחר Permissions:
    • pages_manage_posts
    • instagram_content_publish
    • instagram_basic
    • pages_read_engagement
    • Token Expiration: Never (לא מוצג אם יש System User)
    • לחץ "Generate Token" → העתק ושמור את הטוקן
  6. קבל את Instagram Account ID
    שלב א' — קבל את ה-Page ID. הדבק את הכתובת הבאה (עם הטוקן שלך):
    שלב ב' — קבל את ה-Instagram Account ID. החלף PAGE_ID והטוקן:
    העתק את הערך של instagram_business_account.id מהתשובה.
  7. הוסף ל-Vercel — Environment Variables
    • INSTAGRAM_ACCESS_TOKEN — הטוקן שנוצר
    • INSTAGRAM_ACCOUNT_ID — ה-ID מהשלב הקודם
    • ודא שמוגדרים ל-Production + Preview

אבטחת טריגרים ידניים של Cron Jobs

  1. צור מחרוזת רנדומלית מאובטחת

    אפשרות ב' — אתר מחולל סיסמאות אקראיות (לפחות 32 תווים):
  2. הוסף ל-Vercel — Environment Variables
    • CRON_SECRET — המחרוזת שנוצרה בשלב הקודם
